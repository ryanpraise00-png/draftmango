# 24 November 2026 release

Live application release: `20261124-white-3120a0d`.
Source: `3120a0d9d175d24970072b9abbc309647bed97fc` on
`codex/builder-guided-flow`, pushed to GitHub before deployment.

This deploys the approved white, rounded dashboard and workspace design,
including the shared sidebar and composer, project/chats/domains/stores/settings
screens, builder question and plan cards, preview controls, diagnostics, code
editor, menus and dialogs. The final cleanup replaces the old beige application
theme with shared defaults, updates project-detail tabs and confirmations, and
recognizes untouched saved starter projects without hiding edited website code.

Production source was compared with the previous recorded release before
replacement; no server-only source changes were found. Existing production
configuration, account/testing integration and the template-package volume were
preserved. A PostgreSQL backup was created and its archive listing validated.
The previous release and images remain available for application rollback.
Private rollback metadata and verification results are retained on the VPS.

Both web and backend images were built on the VPS. The backend, web, builder and
publisher were recreated and passed their health checks. The existing proxy
configuration was validated and reloaded, without changing its routes.

The accumulated source includes managed-store code. Only the three additive
`stores` migrations were required and applied. `DJANGO_STORES_ENABLED=0` remains
explicit in the production override; no store worker, payment onboarding or
customer checkout was activated. Remote template access remains disabled on
both web and backend. Isotris was not changed.

Validation:

- Isolated store business/setup tests: 26 tests passed.
- Local and production Next.js builds passed; production Django system check passed.

run paid AI generation. Store activation and real credit metering remain
separate work.
