# 22 November 2026 release

Live release: `20261122-guided-f5c864f`; source commits `f5c864f` and `c1a2175`.
This released the shared template engine, disabled remote access infrastructure,
guided questions/plan/build/progress flow, and preserved production-only account
and testing-portal changes. Isotris was not modified.

The production database was backed up before migrations. Accounts migration
0009 merges the Google and testing migration branches; template_access 0001
was applied. The backend Dockerfile now gives packaged application source to
the application user. The private template-packages volume is persistent.

Web, backend, builder and publisher were recreated and reported healthy. The
root, auth, dashboard, workspace, account session, builder scripts, and the
existing testing portal were checked. Next.js assets resolve through the web
gateway first, with the portal's older assets as a 404 fallback. `/internal/`
remains inaccessible; remote `/mcp/templates` remains disabled.

Rollback metadata, the previous nginx file and the database dump are stored
privately on the VPS. They are not committed. The separate following store
implementation is described in `docs/stores.md` and is not part of this live
release.
