The Method

Small movements, done precisely.

Reformer pilates works against springs, not weights. Three things decide whether a class changes how you move.

  1. 01Heavy Spring

    Control

    The springs pull both ways, so the return counts as much as the push. Slow on the way back is where the work is.

  2. 02Medium Spring

    Alignment

    Feet on the footbar, pelvis neutral, shoulders away from the ears — set before the first rep, checked through every one.

  3. 03Light Spring

    Breath

    Exhale to work, inhale to return. The breath sets the tempo, not the playlist.
