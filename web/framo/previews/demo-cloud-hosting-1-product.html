Click it, or script it.

The dashboard is the friendly way in. When you want to automate, the same machine is one line away.

  • framo CLI for macOS, Linux and Windows
  • One REST API, versioned and documented
  • Terraform and Pulumi providers
# A VM, a database and a deploy, all in fra1
framo vm create api-1 --size s-2vcpu-4gb --region fra1
framo db create pg-main --engine postgres-16 --region fra1
framo deploy --region fra1
# Create a VM with the REST API
curl -X POST https://api.framo.cloud/v2/vms \
  -H "Authorization: Bearer $FRAMO_TOKEN" \
  -d '{"name":"api-1","size":"s-2vcpu-4gb","region":"fra1"}'
resource "framo_vm" "api" {
  name   = "api-1"
  size   = "s-2vcpu-4gb"
  region = "fra1"
}
