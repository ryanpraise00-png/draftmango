What's new in Framo Flow.

A release every two weeks. Here is what changed, why, and what it means for your workflows.

When it happensAny of 1,400 apps Framo FlowSteps, paths, agents v4.12Shipped 9 Oct 2026 Live

  1. v4.129 Oct 2026

    Feature

    Agents can ask for approval mid-run

    An agent can now stop at any step and ask a person before it carries on. Set the rule once — an amount, a customer tier or a kind of action — and the request lands in team chat, email or the app.

    If nobody answers, a reminder goes out after an hour and a backup approver is asked after four. Every decision is kept in the audit log with the run.

    Refund agent asks · step 4 of 6

    Refund $240 to Halden Studio?

    ApproveReject

  2. v4.1125 Sept 2026

    Feature

    Branch on AI confidence scores

    AI steps now return a confidence score from 0 to 100. Use it in a path: send confident answers straight on and route the rest to a person.

    Classify ticket AIConfidence 91 Confidence ≥ 80 → send · below → a person

  3. v4.1011 Sept 2026

    FeatureImprovement

    Bring your own model keys

    Enterprise workspaces can connect their own model provider keys. Usage is billed by your provider, and every call stays in the region you choose.

    Hosted models remain the default and the fallback if your provider is down.

  4. v4.928 Aug 2026

    Improvement

    Search run history by the data a run carried

    Find the run that touched order NX-20931 or the customer called Halden Studio. Search now looks inside the input and output of every step, for the last 30 days.

  5. v4.814 Aug 2026

    Fix

    Retries respect each app's rate limit

    Retried steps now wait for the app's own rate-limit window instead of a fixed delay, so a busy ledger no longer fails the same step three times in a row.

  6. v4.731 Jul 2026

    ImprovementFix

    Promote to live with a side-by-side diff

    Before a draft goes live you now see exactly what changed: steps added, fields remapped and paths moved, with the version you are replacing beside it.
