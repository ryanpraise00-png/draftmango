# Saved-project asset compatibility

This isolated snapshot retains the original hosted asset bytes for projects created before the Draftmango library rebrand. It is not used by new templates or the application theme.

The gateway serves old asset URLs from v1/assets without redirecting. v1/manifest.json pins every tracked asset's SHA-256 hash. Do not edit these assets or rewrite saved project source/locks. New library work belongs in web/draftmango.
