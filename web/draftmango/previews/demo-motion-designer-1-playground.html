01This Week · Exp. 124

Jelly Cube, or how much wobble is too much.

A soft-body test for a client loop that never happened: how stiff can a jelly be before it stops reading as jelly, and how loose before it reads as water?

  1. FormA rounded cube, 40 mm, with a subdivided inner mesh for the simulation.
  2. SimulationTwelve stiffness values side by side; number seven won.
  3. LightOne large soft key from above, a mint rim and a teal floor bounce.
