Any API

Not on the list? Still on the canvas.

Call any API with an HTTP step, catch any event with a webhook, or write the step in JavaScript.

  • Auth handled: OAuth, API keys and signed requests
  • Retries and rate limits built into every call
  • Turn a step you use often into your own app
HTTP requestStep 3 
// Step 3 · Post the order to the warehouse API
export default async function step({ order }, { http, secrets }) {
  const res = await http.post('https://api.warehouse.example/v2/shipments', {
    headers: { Authorization: `Bearer ${secrets.WAREHOUSE_KEY}` },
    json: { ref: order.id, items: order.lines },
    retry: { attempts: 3 },
  })

  return { shipment: (await res.json()).id }
}
